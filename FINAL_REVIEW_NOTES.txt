Before deployment
1. Activate the project's virtual environment and install requirements.txt.
2. Run: python manage.py check
3. Run: python manage.py migrate
4. Test registration and email OTP, login/logout, product/category CRUD, offers, stock movements, cart, checkout, payments, order status, returns/replacements, role permissions, and staff monitoring.
5. Configure DJANGO_SECRET_KEY, DJANGO_DEBUG=False, DJANGO_ALLOWED_HOSTS, and email credentials in the environment before production deployment.
6. Back up the database and media before replacing an existing working copy.

This is a beginner-friendly development project. A successful Python compile does not prove every Django route or workflow works end-to-end.
