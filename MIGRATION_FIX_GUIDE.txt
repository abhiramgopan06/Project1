DATABASE REPAIR

The homepage error about a missing products_product.discount_ends_at column means the SQLite database does not match the current product model.

Beginner steps on Windows
1. Stop the server with Ctrl+C.
2. Open the folder containing manage.py in VS Code.
3. Run: python repair_database.py
4. Start the app with: python manage.py runserver

You can also double-click run_project.bat. It checks migrations, repairs offer-related columns if an older database has recorded a migration without the actual column, checks the Django project, and then starts the server.

Do not delete db.sqlite3. The repair is designed to preserve existing product and user records. Make a backup of db.sqlite3 before running database changes.
