PROJECT 1 - DJANGO E-COMMERCE SHOP
BEGINNER SETUP GUIDE

1. Extract this ZIP.
2. Open the extracted project1 folder in VS Code.
3. Open Terminal in that folder (the folder containing manage.py).
4. Create a virtual environment:
   python -m venv venv
5. Activate it on Windows:
   venv\Scripts\activate
6. Install the required packages:
   python -m pip install --upgrade pip
   pip install -r requirements.txt
7. If you need email OTP, Google sign-in, or Razorpay, copy .env.example to a new file named .env and enter your own settings. Never share real passwords or payment secrets.
8. Check the project:
   python manage.py check
9. Apply database migrations:
   python manage.py migrate
10. Start the development server:
    python manage.py runserver
11. Open http://127.0.0.1:8000/ in your browser.

IF A COMMAND FAILS
- Confirm the terminal is inside the project1 folder.
- Confirm the virtual environment is activated; the terminal usually shows (venv).
- If Django is missing, run: pip install -r requirements.txt
- If database fields are missing, back up db.sqlite3 first, then run: python manage.py migrate
- Stop the server with Ctrl+C.

IMPORTANT
- This is a local development project, not a production-ready deployment.
- Keep .env private. Do not put email app passwords, Google secrets, or Razorpay keys into a shared ZIP.
- Back up db.sqlite3 and media before replacing files.
- Test registration and email OTP, login/logout, product management, cart, checkout, payment success/failure, returns, and role permissions locally.
- Python source compilation passed during review. A full Django system check and browser-based end-to-end testing could not be run in the build environment because Django dependencies were not installed.
