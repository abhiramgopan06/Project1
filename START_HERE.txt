PROJECT 1 - BEGINNER START GUIDE

1. Open PowerShell in this project folder.
2. Create a fresh virtual environment:
   python -m venv env
3. Activate it:
   .\env\Scripts\Activate.ps1
4. Install packages:
   pip install -r requirements.txt
5. Apply database migrations:
   python manage.py migrate   (run this again - it adds the new OTP table)
6. Start Django:
   python manage.py runserver
7. Open http://127.0.0.1:8000/

IMPORTANT:
Do not copy an old env folder into this project. The old environment had mixed Django files.
If PowerShell blocks activation, run:
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
then activate again.

PRODUCT OFFER FEATURE (added)
1. Start the Django project as usual.
2. Run: python manage.py migrate
   This adds the discount_percent field to products.
3. Sign in with a staff/admin account and open Admin Dashboard > Offer for Products.
4. Select a product, enter a percentage from 1 to 90, and click Save Offer.
   Enter 0% to remove the offer. Offers appear on product cards, product details,
   and the cart; discounted prices are also used for checkout and orders.
