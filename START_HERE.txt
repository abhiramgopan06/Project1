PROJECT 1 - DJANGO E-COMMERCE SHOP

Setup
1. Extract the ZIP and open the project1 folder in VS Code.
2. Create a virtual environment: python -m venv venv
3. Activate it on Windows: venv\Scripts\activate
4. Install dependencies: pip install -r requirements.txt
5. Copy .env.example to .env if you need email, Google sign-in, or payment settings.
6. Run: python manage.py check
7. Run: python manage.py migrate
8. Run: python manage.py runserver
9. Open http://127.0.0.1:8000/

Important
- Keep a backup of db.sqlite3 and the media folder before replacing an existing project.
- Do not put real email passwords or payment keys in a shared ZIP.
- The application is intended for local development until production settings and payment/email integrations are tested.
- Run the Django checks above and manually test registration/OTP, product management, cart, checkout, payments, returns, and staff permissions.
- The build environment does not have Django installed, so full Django checks and browser-based end-to-end tests could not be run here.
